METRICS PERFORMANCE — PWA PARA iPHONE/iPAD

Archivos:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png
- icon-512-maskable.png
- apple-touch-icon.png
- vercel.json

Instalación en iPhone/iPad:
1. Publica estos archivos en la raíz del mismo proyecto de Vercel.
2. Abre la URL en Safari.
3. Pulsa Compartir.
4. Pulsa “Añadir a pantalla de inicio”.
5. Abre Metrics Performance desde el nuevo icono.

La lógica existente del dashboard se conserva; los cambios son de instalación/PWA, iconos y adaptación móvil.
